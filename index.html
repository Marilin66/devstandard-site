Comment ça fonctionne ?

Un flux ultra-simple, universel, sans aucun serveur ni base de données à installer.

1

Lancez la commande

Dans le terminal de votre projet (React, Vue, Node, Python, Laravel...), tapez la commande npx github:Marilin66/devstandard-skills add <skill>.

2

Dépôt autonome dans votre projet

Le standard est téléchargé et placé directement dans .agents/skills/<skill>/SKILL.md. Vous pouvez le commiter dans votre Git pour toute l'équipe.

3

L'IA applique les règles

Dès que vous promptez Cursor, Antigravity, Claude Code ou Codex, l'IA charge automatiquement ces instructions et produit un code conforme sans dérive.

Foire Aux Questions

Tout ce que vous devez savoir sur DevStandard.

Est-ce 100% gratuit ?

Oui, entièrement. Tout le corpus de standards et la commande CLI sont open-source sous licence MIT. Aucun compte payant, aucune clé d'API requise.

Dois-je commiter le dossier .agents/skills/ dans mon Git ?

Oui, absolument ! C'est la force de cette approche : en versionnant les skills avec votre code source, tous les développeurs de l'équipe et toutes les IAs qui travaillent sur le dépôt appliquent les mêmes règles de façon déterministe.

Puis-je adapter ou modifier un skill après installation ?

Oui ! Le fichier installé est un simple fichier Markdown standardisé (SKILL.md). Vous pouvez l'éditer pour ajuster une règle selon les besoins spécifiques de votre entreprise ou projet.
