Fonctionnement en 3 étapes

Les standards s'installent dans vos projets existants sans modifier votre environnement ni vos dépendances.

1

Exécutez la commande dans votre projet

Dans le dossier de votre projet (React, Vue, Next.js, Flutter, React Native, Laravel…), exécutez la commande npx github:Marilin66/devstandard-skills add <nom>. Aucune installation globale requise.

2

Le fichier SKILL.md est téléchargé

Le standard est déposé dans .agents/skills/<skill>/SKILL.md — un simple fichier Markdown versionné avec votre code Git. Aucune base de données, aucun serveur, aucun abonnement.

3

L'IA applique les règles automatiquement

Votre assistant IA (Antigravity, Cursor, Claude Code, Codex) lit nativement ces règles et génère des interfaces sobres, du code sécurisé et des architectures robustes conformes aux standards institutionnels.

Foire Aux Questions

Principes, utilisation et philosophie de DevStandard.

Les portails d'État (ANIP Bénin, RAVIP, service-public.fr, GOV.UK, USWDS) et les applications bancaires de référence ont résolu, au fil des années, les problèmes d'accessibilité, de lisibilité, de sécurité et de confiance utilisateur. Leurs patterns sont éprouvés, audités et conformes à des réglementations strictes (RGAA, WCAG 2.2 AA, Section 508). Appliquer ces standards garantit des interfaces crédibles, sobres et immédiatement dignes de production — loin du « design IA générique » aux dégradés violets.
Oui, intégralement. Les standards intègrent les spécifications natives mobiles : cibles tactiles de 44×44pt (iOS HIG) et 48×48dp (Android Material), gestion des Safe Areas et encoches, navigation par Bottom Tab Bar, Bottom Sheets contextuals, et taille minimale de 16px sur les champs de saisie pour éviter le zoom involontaire sur iOS. Les skills sont agnostiques au framework.
Oui. C'est l'essence même du projet. En committant ces fichiers, vous garantissez que chaque développeur et chaque IA intervenant sur le projet appliqueront strictement la même charte d'ingénierie. Ces fichiers Markdown sont légers, lisibles par les humains et versionnés comme n'importe quel fichier de configuration.
Non. DevStandard est entièrement gratuit, sans compte, sans base de données et sans serveur. Les standards sont de simples fichiers Markdown hébergés sur GitHub. La commande npx github:Marilin66/devstandard-skills add <skill> télécharge directement le fichier depuis le dépôt public — c'est tout.
Ouvrez une Pull Request sur github.com/Marilin66/devstandard-skills avec votre nouveau fichier SKILL.md dans le dossier approprié (skills/frontend/, skills/backend/ ou skills/engineering/). Chaque standard doit inclure un frontmatter YAML, une description précise, des exemples de code et une checklist de validation.
