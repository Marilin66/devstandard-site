# DevStandard Site

> Site vitrine, portail de documentation et catalogue public pour **DevStandard** — Registre d'ingénierie logicielle pour assistants IA.

---

## 🚀 Déploiement sur Vercel (1 clic)

Ce site est optimisé pour être déployé instantanément sur **Vercel** :

1. Pousser ce dépôt sur GitHub (ex: `https://github.com/Marilin66/devstandard-site`).
2. Aller sur [Vercel](https://vercel.com/new).
3. Importer le dépôt `devstandard-site`.
4. Cliquer sur **Deploy**.

C'est tout ! Vercel détecte automatiquement la configuration et met votre site en ligne en quelques secondes avec HTTPS gratuit.

---

## 💻 Exécution en Local

```bash
# Avec npx serve
npx serve .

# Ou simplement double-cliquer sur index.html dans votre navigateur
```
